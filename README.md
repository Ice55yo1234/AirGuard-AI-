### 2. โปรแกรมและลิงก์ที่เกี่ยวข้อง

**ชื่อโปรแกรม:** AirGuard AI — ระบบแสดงข้อมูลฝุ่น PM2.5 และช่วยวางแผนกิจกรรมกลางแจ้ง

**รายละเอียดโปรแกรม**  
เว็บแอปพลิเคชันสำหรับตรวจสอบค่าฝุ่น PM2.5 และสภาพอากาศ แสดงแนวโน้มล่วงหน้าสูงสุด 72 ชั่วโมง พร้อมเครื่องมือเปรียบเทียบช่วงเวลาทำกิจกรรมกลางแจ้ง ผู้ใช้สามารถเลือกจังหวัด ใช้ตำแหน่งปัจจุบัน และบันทึกพื้นที่โปรดได้

**ลิงก์โปรแกรมและซอร์สโค้ด**

- เว็บไซต์: Web: https://ice55yo1234.github.io/AirGuard-AI-/#project
- GitHub: https://github.com/Ice55yo1234/AirGuard-AI-/tree/main

**แหล่งข้อมูลที่เกี่ยวข้อง**

- Open-Meteo: https://open-meteo.com/
- Copernicus Atmosphere Monitoring Service (CAMS): https://atmosphere.copernicus.eu/

**สถานะการพัฒนา**  
เว็บไซต์เชื่อมต่อข้อมูลอากาศและแนวโน้มจาก Open-Meteo / CAMS ส่วนโมเดล Machine Learning ของโครงการอยู่ในส่วนงานวิจัยและยังไม่ได้เชื่อมต่อกับผลพยากรณ์ที่แสดงบนเว็บไซต์
